FM26 · Windows 로컬 도구

연예인 리그 시즌 도우미

유소년이 들어온 시즌에 한 번, 기존 게임 DB의 연예인 이름과 사진을 묶어서 배정합니다. CSV를 직접 만들 필요가 없는 흐름을 목표로 합니다.

게임 연결 전
실제 게임에서 쓰기를 검증하지 않은 베타입니다.

별도 세이브에서 먼저 확인하세요. 지원 버전이 맞지 않으면 적용을 차단합니다. 능력치를 고정하고 나이를 조정해도 모든 은퇴를 막는다고 보장할 수 없습니다.

로컬 도구에 연결하는 중입니다.
1

폴더와 커리어 설정

스캔에서 게임 날짜를 읽으면 자동 입력합니다. 읽지 못하면 게임 화면의 날짜를 직접 입력하세요.

선택한 사진을 도구 전용 얼굴팩으로 복사합니다. 원본 사진은 바꾸지 않습니다.

먼저 폴더와 커리어 이름을 저장한 뒤 스캔하면 날짜 읽기를 시도합니다.

이 커리어를 구분할 이름을 계속 사용하세요.

설정을 불러오는 중입니다.
2

읽기 스캔과 첫 등록

FM26에서 세이브를 불러온 뒤 스캔하세요. 읽기 스캔은 게임 데이터를 바꾸지 않습니다.

첫 등록은 현재 선수들을 기록해 이후 새로 발견되는 선수와 구분하는 단계입니다.

아직 커리어 기록이 없습니다.
3

이번 시즌 배정 후보

첫 등록 후 새로 스캔에 나타난 선수를 확인합니다.
