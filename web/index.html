시즌이 바뀌어도, 연예인과 함께

새 유소년에게 이름·사진을 배정하고 기록을 이어갑니다. 구단을 옮겨도 같은 세이브 기록을 사용하세요. 파일은 내 브라우저에서만 처리합니다.

게임에서 이미 생성된 선수의 실제 ID가 필요합니다. 얼굴팩 ZIP과 이름·나이·능력치 수정 목록을 만듭니다. 이름·나이·능력치는 인게임 에디터에서 직접 바꾸어야 하며, 선수 생성·은퇴 방지·게임 자동 편집 기능은 없습니다.

1. 세이브와 시즌 기록

새 세이브는 다른 이름을 사용하세요. 매번 처리한 뒤 기록 JSON을 내려받아 보관합니다. 브라우저에 자동 저장하지 않습니다. 과거 세이브로 돌아가면 그 시점의 기록도 함께 사용하세요.

2. 실제 선수 목록

CSV에 id,name,club,age,gender,newgen,ca,pa,dob 머리글을 사용합니다. 필수값은 실제 ID와 이름입니다. 자동 배정은 여성으로 표시되고, 21세 이하이며, 유소년으로 표시된 선수만 대상으로 합니다.

성별: F 또는 여자 / 유소년: 1 또는 true. CA·PA·생년월일은 선택 사항입니다. 생년월일은 YYYY-MM-DD. 고유 ID·이름·나이·구단 등의 한국어 머리글도 인식합니다. 게임에서 웹 페이지로 출력한 표가 있다면 HTML 파일도 읽을 수 있습니다. 실제 ID가 없는 출력물에는 ID를 추가해야 합니다.

3. 사진과 연예인 이름 목록

기본 목록은 선수용 사진 963장의 하단 이름을 직접 읽은 전체 목록입니다. 같은 사람의 다른 사진과 동명이인도 포함하므로 서로 다른 연예인이 963명이라는 뜻은 아닙니다. 사진 원본 SHA-256도 대조합니다. 현재 갖고 있는 파일을 선택하면 되며 사진을 다시 받을 필요는 없습니다. 기존 선수의 잘못된 연결을 고치려면 별도의 얼굴 복구 페이지를 사용하세요.

name,path,sha256 머리글을 사용합니다. path는 선택한 폴더 안의 PNG 상대 경로, sha256은 모르면 빈칸입니다. 새 사진과 이름을 추가하면 다음 배정부터 사용할 수 있습니다. 기존 배정은 기록에 남습니다.

첫 시즌에는 기존 여성 선수 목록을 넣고 ‘기준 선수 목록만 기록’을 누른 뒤 JSON을 저장하세요. 이 버튼은 연예인 배정을 하지 않습니다. 이후 유소년 입단 때 해당 유소년 목록과 지난 JSON을 사용하면 됩니다.

밀림 대조는 실제 선수 이름과 사진의 확인된 이름이 정확히 같은 경우만 연결합니다. 동명이인·약칭·목록에 없는 사진은 자동 처리하지 않습니다. 기존 생성 선수는 r-ID, 기본 DB 선수는 숫자 ID로 출력하므로 내보내기 전 선수 종류를 확인하세요.

4. 배정 결과와 내보내기

사진ID기존 이름배정 이름사진 경로

ZIP의 config.xml과 fm26_celeb_실제ID.png 사진들을 같은 새 폴더에 두고 현재 게임이 읽는 graphics 안에 넣습니다. FM26의 그래픽 호환성 보고를 고려해 같은 폴더와 고유 파일명을 사용합니다. 같은 ID가 있는 이전 시즌 도우미 폴더는 graphics 밖으로 빼고 교체해 중복을 피하세요. 다른 얼굴팩의 동일 ID도 확인하고 게임을 완전히 종료한 뒤 다시 실행해 표시를 확인합니다.

CSV는 게임이 자동으로 읽는 파일이 아닙니다. 배정 이름을 인게임 에디터의 이름 항목 또는 게임의 별명 기능으로 직접 입력해야 합니다. 별명은 표시 범위가 다를 수 있습니다. 사진을 연결해도 원래 이름은 그대로입니다.

5. 기존 선수 장기 유지 점검

첫 기록의 CA·PA를 기준으로 현재 능력치 하락과 고령 선수를 찾습니다. 첫 기록에 없던 선수는 새 기준으로 등록됩니다. 이미 일어난 은퇴를 되돌리지는 못합니다.

대상은 입력 목록의 여성 선수 전체입니다. 생년월일 변경 제안과 원래 CA·PA를 적어 줍니다. 세부 능력치는 따로 저장·복원하지 않으므로 CA만 바꿔도 같은 분배가 복원되지는 않습니다. 경기 진행 전 별도 저장 후 에디터에서 확인하며 조정하세요.
