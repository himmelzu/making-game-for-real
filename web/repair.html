선수 이름에 맞는 연예인 사진 다시 연결하기

현재 게임의 실제 선수 ID와 사진 아래에 적힌 이름을 대조해, 기존 얼굴팩의 config.xml 교체 파일을 만듭니다. 게임이나 세이브 파일에 접근하지 않으며 선택한 파일을 인터넷으로 보내지 않습니다.

전체 사진을 한 번에 같은 번호만큼 밀지 않습니다. 사진에 적힌 이름과 검수한 별칭을 현재 세이브의 실제 ID·이름 목록과 대조합니다. 이름이 명단과 사진 목록에서 각각 하나뿐인 경우만 연결합니다. 동명이인과 실제 ID를 확인하지 않은 선수까지 자동으로 고쳤다고 표시하지 않습니다. 이름·국적·능력치는 바뀌지 않습니다.

검수 사진 목록을 읽는 중입니다.

1. 현재 쓰는 celeb 폴더 선택

사진만 선택하면 기존의 잘못된 연결을 제거할 수 없습니다. SM/config.xml, 플레디스/config.xml 등을 포함한 얼굴팩 전체를 선택하세요. EXE·CMD 등 다른 파일은 읽지 않습니다. 원본은 수정하지 않습니다.

선택한 폴더가 없습니다.

2. 실제 게임의 선수 ID·이름 입력

현재 세이브에서 알려주신 제시카 2002043293·이현주 2002043294입니다. 관련 원본 config와 사진 4장의 해시가 같을 때만 이 버튼을 켭니다. 다른 선수의 ID를 추정하지 않습니다.

현재 세이브의 여자 연예인 선수 목록을 사용하세요. 필수 열은 id,name이고 club은 선택입니다. 한국어 고유 ID,이름,구단 머리글과 탭 구분 표도 읽습니다. ID를 숫자만 보고 추정하거나 사진 파일명에서 복사하지 마세요.

선수 목록에 ID가 없다면 그 파일만으로는 자동 복구할 수 없습니다. 게임의 고유번호 표시 기능이나 실제 프로필에서 번호를 확인해 추가하세요. 사용 중인 FM26 화면이 목록 출력이나 ID 열을 제공한다고 가정하지 않습니다. 정확한 이름과 검수한 별칭만 대조하며 동명이인은 제외합니다.

3. 변경 내용 확인

기존 사진의 r- 유무를 그대로 유지합니다. 수정 대상 ID에 다른 사진이 연결된 경우, 해당 잘못된 매핑도 다른 폴더까지 검사해 제외합니다. 아직 검수하지 않은 사진이 연결을 잃을 수 있으며 아래에서 따로 표시합니다.

백업은 graphics 폴더 밖에 보관하세요. 새 파일은 원본과 같은 위치의 config.xml을 교체하는 용도입니다. 예전 config를 다른 이름의 XML로 같은 그래픽 폴더에 남기거나 새 팩을 덧붙이는 방식은 사용하지 마세요.

4. 기존 얼굴팩에 적용

  1. 현재 celeb 폴더 또는 그 안의 원본 config를 graphics 밖에 백업합니다.
  2. 다운로드한 ZIP을 먼저 별도 임시 폴더에 풉니다. SM/config.xml 같은 폴더 구조와 REPAIR_README.txt를 확인합니다.
  3. ZIP의 하위 폴더들을 현재 celeb 폴더 안에 복사해 기존 config.xml을 교체합니다. 원래 PNG는 그대로 둡니다. 이 ZIP에는 사진이 없습니다.
  4. 게임을 완전히 종료하고 다시 실행해 세이브를 불러옵니다. 버전에서 제공하는 그래픽 캐시 초기화·새로고침 기능도 사용할 수 있습니다.
  5. 대조한 선수의 이름·사진을 확인합니다. 다른 위치에 같은 선수 ID를 연결한 config가 있으면 그쪽도 별도로 확인해야 합니다. 되돌릴 때는 백업한 원래 config를 복원합니다.

얼굴 연결 교체만으로는 새 게임이 필요하지 않습니다. 실제 FM26에서의 표시 결과는 적용 후 확인해야 합니다. 국적·구단 규칙을 바꾼 FMF의 새 게임 요구와는 별개입니다.
