FM26 · LOCAL FACE PACK TOOL

유소년에게 연예인 얼굴 연결하기

기존 얼굴팩의 PNG 사진을 골라, 게임에 이미 등장한 유소년의 ID에 연결합니다. 사진과 ID는 이 브라우저 안에서만 처리하며 인터넷으로 전송하지 않습니다.

설치 없이 · 오프라인 사용 · 원본 보존

이 도구는 얼굴 연결 파일만 만듭니다. 선수 생성, 선수 이름 변경, 나이·능력치·은퇴 변경 기능은 없습니다. 생성 선수의 r-숫자와 기본 DB 선수의 숫자 연결을 선택할 수 있으며 FM26에서 실제 얼굴 표시 여부는 적용 후 확인해야 합니다.

1. 기존 얼굴 사진 폴더 선택

기본으로 스텝·스태프·staff라는 이름의 하위 폴더를 제외합니다. 체크를 바꾸면 기존 미리보기가 지워지므로 다시 만들어 주세요.

하위 폴더의 PNG도 함께 찾습니다. 얼굴팩 전체가 커도 선택한 사진만 새 ZIP에 들어갑니다. 같은 이름의 사진이 여러 폴더에 있어도 별도로 다룹니다. 기존 config.xml이나 EXE 파일은 읽지 않습니다.

선택한 폴더가 없습니다.

2. 게임에서 확인한 유소년 ID 입력

쉼표·공백으로 구분해도 됩니다. 빈 입력과 중복 ID는 허용하지 않습니다. 한 번에 최대 500명까지 연결합니다. 프로필의 ID 표시 기능이 있는지 게임 설정에서 확인하고, 반드시 해당 유소년의 실제 ID를 사용하세요.

새 게임 시작부터 있는 유소년은 기본 DB 선수일 수도 있고 시작 시 생성된 선수일 수도 있습니다. 나이, 20억대 ID 또는 ‘유소년’이라는 이유로 r-를 단정하지 마세요. 종류가 다른 선수는 나누어 출력하고 한 명씩 실제 표시를 확인하세요.

3. 선수별 사진 확인

‘사진 선택’으로 각 선수의 사진을 바꿀 수 있습니다. 같은 사진을 여러 선수에게 연결할 수도 있습니다. 새 미리보기를 만들면 사진 연결을 처음부터 다시 배정합니다.

    4. 게임에 적용

    face_0001.png라는 파일명 자체가 문법 오류는 아닙니다. 사진 파일명은 선수 ID일 필요가 없고, config의 from이 파일명을 지정합니다. 다만 FM26에서 같은 파일명과 하위 사진 경로에 관한 표시 문제 보고가 있어, 이 버전은 실제 ID가 들어간 고유 파일명을 config.xml 옆에 배치합니다.

    예를 들어 from="fm26_celeb_2002079023"는 같은 폴더의 fm26_celeb_2002079023.png를 찾고, to="graphics/pictures/person/r-2002079023/portrait"가 게임 속 선수를 지정합니다. 아래처럼 PNG와 config를 나란히 두세요.

    graphics/
└─ newfolder/                 ← 새 빈 폴더, 이름은 자유
   ├─ config.xml
   ├─ fm26_celeb_2002079023.png
   └─ READ_ME.txt
    1. 다운로드한 ZIP을 풀어 config.xml과 fm26_celeb_실제ID.png 파일이 같은 폴더에 있는지 확인합니다.
    2. 현재 기존 얼굴팩이 정상 표시되는 FM26의 graphics 폴더 아래에 새 빈 폴더를 만들어 두 항목을 함께 넣습니다. 예를 들어 시즌마다 별도 폴더 이름을 사용하세요. 기존 얼굴팩이나 팀 로고 폴더에 덮어쓰지 않습니다.
    3. 게임 설정에서 그래픽 캐시 비우기·스킨 새로고침 기능을 사용할 수 있는지 확인하고, 다시 불러온 뒤 해당 유소년의 얼굴을 확인합니다. 메뉴 명칭과 적용 방식은 FM26 버전에 따라 확인이 필요합니다.
    이전 faces/face_0001 출력이 올바르게 배치됐는데도 표시되지 않을 때

    이전 출력은 파일이 모두 있고 XML 문법이 맞아도 FM26 호환성 문제나 다른 팩의 같은 파일명 때문에 표시되지 않을 수 있습니다. 새 버전으로 다시 내보내거나, 기존 PNG를 config 옆으로 옮겨 fm26_probe_2002079023.png처럼 고유 이름으로 바꾸고 from도 fm26_probe_2002079023으로 맞춰 한 명을 시험하세요. 실제 선수 ID에 해당하는 to와 r-는 유지합니다. 이전 같은 ID 팩은 graphics 밖으로 빼고 게임을 완전히 종료한 뒤 다시 실행합니다. 이 방법의 실제 게임 결과는 확인이 필요하며 선수 이름은 바뀌지 않습니다.

    참고: FM26 생성 선수 사진의 하위 경로 문제 보고 · FM26 사용자 그래픽과 고유 파일명 안내

    사진 한 장 최대 20MiB, 한 번의 ZIP에 사용하는 사진 합계 최대 128MiB입니다. 큰 얼굴팩은 선택할 수 있으며, 출력에 사용하는 사진의 합계만 제한합니다. PNG 파일은 편집하거나 다시 압축하지 않고 그대로 복사합니다.

    선택: 압축을 푼 얼굴팩 폴더 배치 확인

    ZIP을 푼 뒤 config.xml과 PNG가 들어 있는 폴더를 선택하세요. 이전 버전의 faces 하위 폴더도 검사할 수 있지만 경로 일치는 FM26 표시 성공을 보장하지 않습니다. 사진 경로·실제 PNG 위치·헤더와 하위 경로 호환성 주의사항을 읽기 전용으로 대조합니다. 파일을 수정하거나 전송하지 않으며 EXE·CMD 등 그 외 파일은 읽지 않습니다.

    검사할 폴더를 선택해 주세요.

    검사 범위는 선택한 폴더 안입니다. 올바른 선수 ID인지, 얼굴과 이름이 같은 인물인지, 다른 얼굴팩과 충돌하는지, 게임이 이 graphics 경로를 사용하는지는 별도로 확인해야 합니다. PNG 헤더가 맞아도 이미지 전체가 손상되지 않았음을 보장하지는 않습니다.
