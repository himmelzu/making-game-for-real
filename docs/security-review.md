# Windows 자동화 v3 배포 중단

2026-10-18 사용자가 `fm26-auto-beta-v3.zip`을 GitHub에서 다운로드할 때 Windows 보안이 차단·제거했다고 보고했습니다. 보고된 탐지 이름은 **`Trojan:Script/Sabsik.Fl.A!ml`**이고, 영향 항목은 다운로드 ZIP을 가리키는 `webfile` 기록입니다. 이 기록은 ZIP 내부 어느 파일이 원인인지까지 보여 주지는 않습니다.

실행 패키지를 현재 `main`에서 회수하고 배포 생성 명령을 비활성화했습니다. 과거 커밋에는 조사용 기록이 남아 있지만, 과거 버전으로 내려받아 실행하지 마세요. 악성코드 여부 또는 오탐 여부를 확정하지 못했습니다. 백신을 끄거나 예외 등록·격리 복원·다른 실행기로 우회하라고 안내하지 않습니다.

## 정적으로 확인한 사실

- 배포 ZIP SHA-256: `625aa0dcbf39a5604baf421b647dce029486f18a61a28fb095bec6e30446ff6a`.
- ZIP CRC와 선언된 내부 파일 57개의 크기·해시가 맞으며, 미선언 파일은 없었습니다.
- 코드·자료·문서는 저장소 원본과 일치하고, CMD는 보존된 실행기와 줄바꿈 외에 차이가 없습니다.
- 동봉 Python은 공식 HTTPS에서 다시 받은 CPython 3.14.8 Windows x64 embeddable ZIP과 대조했습니다. 공식 ZIP SHA-256은 `a93abe456ab01bd96d7a085b3cdb6566b3063f4241360d114142fbdb07f0a310`입니다. 의도한 `python314._pth` 외의 런타임 파일은 일치합니다.
- 소스 검사에서 외부 전송, 추가 프로그램 다운로드, 자동 시작 등록, 백신 설정 변경은 발견하지 못했습니다.
- 도구는 `fm.exe` 프로세스 메모리를 읽고 수정합니다. 폴더 선택 창에는 고정된 PowerShell 명령을 사용합니다. 이런 동작이 탐지 원인인지는 확인하지 못했습니다.

위 검사는 출처·포장 일치 확인입니다. Windows 백신 검사 통과나 실제 게임에서의 안전성 검증을 의미하지 않습니다. 탐지명만으로 파일의 구체적인 악성 동작을 설명하거나 오탐이라고 단정할 수 없습니다. Windows에서 패키지를 실행하지 않고 조사했습니다.

## 사용자 측 처리
