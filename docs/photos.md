# 사진 수와 ID 밀림

공개 원본 그래픽 ZIP에는 얼굴 PNG 1,010장이 있습니다. 그중 스태프 폴더 47장을 빼면 선수용으로 분류한 사진은 963장입니다. 모든 사진은 350×350 PNG이며 깨진 파일·빠진 매핑·중복 매핑 대상·완전히 동일한 이미지 해시는 발견하지 않았습니다. 서로 다른 사진이 모두 서로 다른 인물이라는 뜻은 아닙니다.

900명 모두를 보지 못한 느낌은 사진 수와 게임 속 선수 수가 같지 않아서 생길 수 있습니다. 페이스팩은 얼굴 연결만 하고 선수를 추가하지 않습니다. 다른 팀·자유계약 선수, 생성 여부와 DB 로딩 범위, 국적·영입 제한·검색 필터, 실제 ID와 다른 사진 연결도 함께 영향을 줄 수 있습니다. 원 제작자의 ‘8,120명’ 기준은 단독 연예인 V2 안내여서 500팀 통합판의 정상 인원 기준으로 그대로 쓰지 않습니다.

플레디스 28장은 인쇄된 자막 이름과 XML의 후보 ID가 +7에서 대응했습니다. 다른 폴더 표본에는 +18과 SM의 `1.png` 같은 특수 매핑도 있습니다. 전체 +7은 적용하지 않습니다. XML 후보가 실제 새 게임 ID로 고정된다고 보장할 수도 없습니다.

새 도구에는 자막 텍스트를 직접 읽어 확인한 118장의 이름·상대 경로·SHA-256을 넣었습니다. 얼굴 인식으로 사람을 식별한 목록이 아닙니다. 기본 이름 목록에 없는 845장은 이름·사진 연결 검수가 남았습니다. 번호만 보고 잘못된 이름을 자동 부여하지 않았습니다. 같은 이름이 두 번 등장할 때 기존 선수 대조에서는 제외하고, 새 유소년 배정에서는 각 사진의 경로로 구분합니다.

**사진을 재사용하면 필수 추가 사진은 0장입니다.** 963장을 전부 자동 이름 목록으로 쓰려면 남은 사진의 이름 표기가 필요합니다. 새 사진만 구해도 충분한 것이 아니라, 실제 이름과 사진 경로가 일치하는 CSV를 함께 준비해야 합니다. 최신 연예인 명단을 검증해 새로 추가한 버전은 아닙니다.

여성 메가팩 설정 7,591개와 연예인 설정 1,010개는 대상 경로와 숫자 ID가 모두 겹치지 않았습니다. 따라서 받은 설정 파일끼리의 충돌이 현재 밀림 원인이라는 증거는 없습니다. 여성 메가팩의 실제 이미지 파일은 받지 않아 파일 유무까지 검사하지 못했습니다. 전체 설정 파일 재생성이나 로딩 순서 변경으로 연예인 이름·얼굴 불일치를 해결했다고 주장하지 않습니다.

개별 사진을 직접 선택하려면 `web/face.html`, 이름과 실제 ID로 검수한 사진을 다시 연결하려면 `web/index.html`의 기존 선수 사진 밀림 대조를 사용합니다. 그림 아래 이름과 미리보기도 확인한 뒤 적용하세요.
