# FM26 단일 XML 통합 데이터 적용 방법

압축 안의 `FM26_unified.xml` 하나만 사용합니다. 실행 프로그램을 설치할 필요가 없습니다.

## 왜 v2에는 XML이 세 개였나요?

세 파일은 함께 켜는 추가 파일이 아니라, 바꾸는 범위를 선택하는 대체 버전이었습니다.

- `cups.xml`: 컵 대회 수정.
- `longplay_young.xml`: 위 컵 수정 + 기존 연예인 선수 시작 나이 조정.
- `longplay_world_experimental.xml`: 위 두 내용 + 기존 연예인 선수 주 국적 분산.

이번 `FM26_unified.xml`은 세 번째 파일의 이름을 알기 쉽게 바꾼 사본입니다. XML 내용을 이어 붙이거나 대회를 다시 추가하지 않았습니다. 파일의 내용과 규칙은 v2의 세 번째 파일과 완전히 같습니다. 이미 그 파일을 검증했다면 같은 데이터를 다시 받는 셈입니다.

## 들어 있는 내용

- 기존 6단계 승강제 리그를 유지합니다.
- 기존 내셔널리그컵을 4~6부 400팀으로 확대합니다.
- 여자 포칼 챌린지(1~3부 100팀), 여자 FA 트로피(5~6부 280팀), 여자 FA 바스(6부 40팀)를 추가합니다.
- 확인된 기존 연예인 선수 771명의 시작 나이를 2025년 7월 1일 기준 18~22세로 맞춥니다. 이 중 105명은 배정 생년이 원래와 같아 실제 생년 변경은 666명입니다. 게임 시작일이 다르면 나이도 달라집니다.
- 이 771명의 주 국적을 대한민국·일본·중국·호주·잉글랜드·프랑스·독일·스페인·네덜란드·스웨덴·노르웨이·덴마크·이탈리아·브라질·캐나다·미국에 48~49명씩 분산합니다.

컵은 실제 축구 컵 대회의 발상을 이 통합 리그에 맞춘 창작 여자 대회입니다. 현실 대회의 참가 자격과 일정을 그대로 재현하지는 않았습니다.

## 에디터에서 게임까지

1. ZIP 압축을 전부 풉니다. `FM26_unified.xml`과 `적용방법.txt`가 나옵니다.
2. Steam의 별도 **Football Manager 26 Editor**를 실행하고, 기존 모드에 맞는 기본 데이터베이스를 불러옵니다. 게임 속 인게임 에디터가 아닙니다.
3. 파일 메뉴의 **XML 가져오기** 기능으로 `FM26_unified.xml` 하나를 불러옵니다. 메뉴 이름이 다르면 에디터 데이터 가져오기에서 XML을 선택합니다. 다른 모드나 v2 XML을 먼저 불러와서 합치지 마세요.
4. **규칙 시험/검증**에서 전체 리그를 선택해 **6부까지** 검증합니다. 통과하기 전에는 플레이용 완성본으로 취급하지 않습니다.
5. 검증에 통과하면 파일 메뉴에서 **에디터 데이터 다른 이름으로 저장**을 사용해 `FM26_unified.fmf`로 저장합니다. XML의 확장자만 FMF로 바꾸는 방법은 안 됩니다. OneDrive 경로에 문제가 있으면 먼저 로컬 폴더에 저장합니다.
6. 저장한 FMF를 **FM26이 실제로 사용하는 사용자 데이터 폴더의 `editor data`**에 넣습니다. 에디터 저장 창의 기본 위치부터 확인하고, 게임에서 파일이 안 보이면 사용자 데이터 경로를 확인하세요. PC마다 Documents·OneDrive·AppData 경로가 다를 수 있으므로 추정한 경로에 복사하지 않습니다.
7. **새 커리어**를 만들고 에디터 데이터 선택에서 이 통합 FMF 하나만 켭니다. 원본 여자슈퍼연예인리그 FMF, `ai update.fmf`, v2의 다른 변형을 함께 선택하지 마세요. 같은 리그·선수 데이터가 겹칩니다.
8. 원 제작자 안내대로 여자 **스페인 리그를 6부까지** 선택하고 남자 리그는 없음으로 시작합니다. 얼굴팩은 별도로 기존 것을 사용합니다. 이 XML은 기존 사진 ID 밀림을 자동으로 고치지 않습니다.
9. 시작 후 선수 나이, 영입·등록·출전 가능 여부, 컵 일정과 참가팀을 확인합니다. 첫 시즌뿐 아니라 다음 시즌 컵 개최와 승강도 확인해야 합니다.

기존 세이브에 이 파일을 추가해도 리그·컵·시작 나이·주 국적 변경이 소급 적용되지는 않습니다.

## 국적 분산과 국가대표에 관해

**국적 분산은 실험 설정입니다. 국가대표 대회를 활성화한 완성본은 아닙니다.** 이 파일에는 새 국제대회 규칙이 없고 `international_rule_group`은 비어 있습니다. 기존 모드의 리그 인가와 국가/대륙 비활성화 조건도 그대로입니다.

원 제작자는 연예인 구단에 자국 선수만 영입·출전할 수 있는 제약이 있다고 안내했습니다. 여기서는 그 제약을 해제하지 않았습니다. XML에서 확인한 SM·YG·JYP·HYBE 등을 포함한 38개 구단의 국적 변경 기록은 기존 국가 ID 774를 그대로 사용합니다. 선수 국적 분산과 충돌할 가능성이 있어 에디터 규칙 검증이 통과해도 실제 영입·등록·출전·대표팀 소집까지 확인해야 합니다. 이 문제가 해결됐다고 주장하지 않습니다.

## 이 데이터에 포함되지 않는 기능

유소년 이름·사진 자동 적용, 노화·능력치 하락·은퇴 방지는 이 XML의 기능이 아닙니다. 시작 나이 조정은 영구적인 나이 고정이 아닙니다. 실행 중인 게임을 수정하는 자동화 프로그램도 이 ZIP에 포함하지 않았습니다.

ZIP에는 XML 하나와 이 설명 TXT만 들어 있습니다. CMD·EXE·DLL·Python 런타임은 없습니다. 구성 변경만으로 백신 탐지가 없다고 보장할 수는 없습니다. 보안 프로그램이 계속 차단하면 차단 해제나 예외 등록으로 실행을 강행하지 마세요.
