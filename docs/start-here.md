# 적용 순서

추가 확인 요청 없이 준비한 통합판입니다. 완성된 자동 유소년·불로 선수 모드로 오해하지 않도록 파일별 상태를 구분합니다.

## 먼저 사용할 수 있는 파일

`base/ai_update_user_saved.fmf`는 사용자가 FM26 Editor에서 저장해 보내 준 `ai update.fmf`와 완전히 같습니다. SHA-256은 `54225f7fea315c3a0b48ee64ab7794964bd5c398af0f4feeaf96d436e0120caf`입니다. 이 사본에 나이·국적·자동 생성 기능을 추가했다고 주장하지 않습니다. 기존 파일을 계속 사용할 때는 중복 선택하지 마세요.

도구는 `web/index.html`을 더블클릭해 사용합니다. 별도 설치나 서버가 필요 없는 정적 HTML/JavaScript이며, Windows 자체 실행 검증은 아직 못 했습니다. 최신 Edge/Chrome을 권장합니다. 사진과 선수 데이터는 인터넷으로 보내지 않습니다.

1. 첫 시즌에 세이브 구분 이름과 실제 게임 날짜를 입력합니다.
2. 실제 ID·이름·성별이 있는 기존 여성 선수 목록을 CSV 또는 HTML 표로 넣고 **기준 선수 목록만 기록**을 누릅니다. CA·PA를 포함하면 유지 점검에 활용할 수 있습니다.
3. **시즌 기록 JSON 저장**을 눌러 날짜별로 보관합니다.
4. 유소년 입단 때 지난 JSON을 불러오고, 실제 새 유소년의 ID·이름·나이·성별을 넣습니다. `newgen=1`로 지정하거나, 전원이 유소년인 목록일 때만 해당 체크를 사용합니다.
5. 기존 `celeb` 사진 폴더를 선택하고 배정합니다. 118장 기본 목록을 모두 사용하면 이름·사진을 반복합니다. 이름 목록은 사용자 CSV로 교체할 수도 있습니다.
6. 얼굴팩 ZIP을 내보내고, 이름 CSV를 보며 인게임 에디터 또는 별명 기능에서 직접 이름을 바꿉니다. CSV를 게임 폴더에 넣는 것만으로는 이름이 바뀌지 않습니다.
7. 새 기록 JSON을 다시 저장합니다. 감독이 다른 구단으로 이적해도 같은 세이브 이름·JSON을 사용합니다.

실제 ID는 게임에서 확인한 값을 써야 합니다. XML의 low32 후보나 기존 사진 파일 번호는 실제 새 게임 ID와 다를 수 있습니다. CSV 샘플의 ID도 가상 숫자입니다. 게임에서 선수 목록 출력 시 ID 열을 제공하지 않는다면 별도로 확인해 추가해야 합니다. 일반 세이브 파일을 자동 해독하는 기능은 없습니다.

얼굴팩은 한 묶음 300명씩, 사진 합계 128MiB 이하로 출력합니다. 더 크면 해당 묶음의 인원을 간단 도구에서 나누어 만드세요. 같은 ID를 가진 이전 도우미 폴더는 새 것으로 교체하고, 다른 팩과의 중복 매핑도 피합니다. 새 선수는 보통 `r-ID`를 사용하며, 기본 DB 선수는 숫자 ID를 선택해야 합니다. 캐시와 그래픽을 새로고침한 뒤 게임에서 확인합니다.

## 새 게임용 XML 선택

XML은 **하나만** FM26 Editor에서 가져와 전체 6부까지 규칙 검증을 하고, 다른 이름의 FMF로 저장합니다. 원본·수정본을 함께 체크하지 않습니다. XML의 확장자를 FMF로 바꾸면 안 됩니다. FM26 Editor를 실행할 수 없는 이 클라우드에서는 새 XML을 FMF로 컴파일하지 못했습니다.

| 파일 | 바꾸는 범위 |
| --- | --- |
| `editor/cups.xml` | 내셔널리그컵을 4~6부 400팀으로 확대, 새 컵 3개 추가 |
| `editor/longplay_young.xml` | 위 컵 + 확인된 기존 연예인 771명을 2025-07-01 기준 18~22세로 조정 |
| `editor/longplay_world_experimental.xml` | 위 내용 + 그 771명의 주 국적을 16개국으로 분산 |

나이 조정은 기존 생일의 월·일을 유지합니다(2월 29일은 28일). 105명은 배정 생년이 원래와 같고, 실제 생년 변경은 666명입니다. 원 제작자 명단 전체 960명을 모두 특정했다는 뜻은 아닙니다. 시작일이 다르면 나이가 달라지며, 생년 변경이 과거 경력·계약일을 모두 다시 쓰지는 않습니다. 새 게임에서 나이·계약·선수 등록도 확인해야 합니다.

국적 실험판은 대한민국·일본·중국·호주·잉글랜드·프랑스·독일·스페인·네덜란드·스웨덴·노르웨이·덴마크·이탈리아·브라질·캐나다·미국에 48~49명씩 배치합니다. 국적은 게임 속 설정입니다. 대표팀 출장 이력·선언 국가·구단의 자국 선수 전용 제한을 임의 삭제하지 않았습니다. 기존 제약과 충돌할 수 있으므로 이 실험판을 기본 추천으로 선택하지 않습니다.

**국적 분산만으로 국가대표 대회가 활성화되지는 않습니다.** 사용자가 보낸 규칙 시험 성공 화면에도 다른 국가/대륙 비활성화 안내가 있습니다. 새 수정본에서 파일의 리그 인가 목록, 여자 국가대표팀, 국제대회와 소집, 외국인 영입·등록이 실제로 작동하는지 별도 확인해야 합니다. 국제대회 규칙 자체를 새로 만든 버전은 아닙니다.

## 컵 구성

- 여자 포칼 챌린지: 1~3부 100팀, 7라운드.
- 여자 FA 트로피: 5~6부 280팀, 9라운드.
- 여자 FA 바스: 6부 40팀, 6라운드.
- 기존 내셔널리그컵: 4~6부 400팀으로 확대.

실제 포칼·FA Trophy·FA Vase의 발상을 통합 리그 규모에 맞춘 창작 여자 대회입니다. 현실의 여자 대회 참가 규정과 똑같지는 않습니다. 추가 컵끼리 참가팀이 겹치는 같은 날짜는 피했지만, 리그·국가대표 일정과 향후 시즌 자동 이동까지 보장하지는 않습니다. 6부 팀의 새 컵 최대 추가 경기는 15경기여서 모든 대회를 끝까지 치르면 부담이 늘어납니다. 컵이 반복 개최되는지와 시즌 종료·승강도 게임에서 시험해야 합니다.

## 20~30년 플레이의 남은 한계

매년 FM이 생성한 유소년을 도구로 받아 이름과 얼굴을 배정하는 방식입니다. 새 선수를 게임에 자동으로 만들거나, 실제 신인 연예인을 매년 인터넷에서 찾아 추가하지 않습니다. 30회 반복 테스트는 도구의 기록 유지 시험입니다.

기존 선수의 나이·CA 하락은 유지 점검 CSV로 찾아 인게임 에디터에서 직접 관리해야 합니다. 에디터 버전이 제공하는 생년월일·이름·능력치 항목을 확인하세요. CA만 복원해도 원래 세부 능력치 분배로 돌아가지는 않습니다. 이미 은퇴한 선수나 확정된 은퇴 계획을 자동 취소하는 기능은 없습니다. 시작 나이 조정과 높은 타고난 체력도 영구적인 노화 방지 기능은 아닙니다.

경기 진행 전 수동 보정을 할 때는 별도 세이브를 남기세요. 새 게임·세이브를 되돌린 경우에는 그 세이브에 맞는 기록을 사용해야 ID가 다른 사람에게 연결되지 않습니다.
