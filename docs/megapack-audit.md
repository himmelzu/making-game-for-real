# 여성 메가팩 config와 연예인팩 대조

**두 팩의 사진 연결 대상은 겹치지 않습니다.** 새로 올린 여성 메가팩 `config.xml`의 7,591개 연결과, 원본 연예인팩의 33개 config에 있는 1,010개 연결을 전수 대조했습니다. 원본 파일은 수정하지 않았습니다.

20억이라는 구분은 숫자 집계용입니다. 이것으로 선수가 기존 인물인지, 생성 선수인지, 여성인지 또는 어떤 인물인지 판단하지 않았습니다. `r-`는 경로의 일부이므로 임의로 추가·삭제하지 않았습니다.

연예인팩은 전부 `person/r-숫자/portrait` 형식이고 여성 메가팩은 전부 `person/숫자/portrait` 형식입니다. 숫자 부분도 겹치지 않으므로, **현재 확인한 두 config가 공존한다는 사실만으로 사진 충돌이나 선수 ID 밀림의 원인이라고 볼 수 없습니다.** 같은 대상에 여러 사진이 매핑될 때의 우선순위를 확인한 것은 아닙니다. 이번 비교에서는 그러한 중복 대상 자체가 없었습니다.

## 추가 관찰

7,591개 중 한 항목은 파일 기본이름과 대상 ID가 다릅니다.

```xml
<record from="20002310209" to="graphics/pictures/person/2822441025/portrait"/>
```

파일 이름과 대상 번호가 다르더라도 config가 명시적으로 연결할 수 있으므로 그 자체가 오류는 아닙니다. 실제 사진을 받지 않아 해당 파일의 존재는 검증하지 않았습니다. 파일 이름을 대상 번호에 맞춰 임의 변경하면 기존 연결을 망가뜨릴 수 있습니다.

## 확인 범위

- 여성 메가팩은 config만 받았으므로 **실제 7,591장의 사진 파일 존재·파일명·이미지 무결성은 미확인**입니다.
- 사용자 PC에서 실제 설치한 다른 config, 게임 그래픽 캐시, 스킨 설정, 로딩 순서는 미확인입니다.
- 비교한 연예인팩은 사용자가 제공한 공개 Drive의 `graphics.zip`입니다. 그 안의 플레디스 config는 사용자가 앞서 별도 첨부한 config와 바이트 단위로 같았습니다. 업로드한 대용량 `celeb.zip` 전체와 같은 버전인지는 미확인입니다.
- config는 사진과 게임 내부 인물 번호를 연결합니다. 이 파일을 함께 설치하는 것만으로 유소년 생성·선수 국적·국가대표 대회가 바뀌지는 않습니다.
- 연예인팩의 원본 번호와 현재 로스터·새 세이브의 실제 인물 번호가 어긋나는 문제는 별도로 확인해야 합니다.
