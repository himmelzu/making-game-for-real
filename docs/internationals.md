# 여자 국가대표와 월드컵: 확인한 내용과 설정 방법

구단의 자국 선수 제한과 국가대표 참가 자격은 서로 다른 설정입니다. 구단에서 여러 국적의 선수를 영입·출전하게 하면서, 선수들은 각자의 국가대표팀으로 뛰도록 구성하는 방향은 가능합니다. 다만 이 문서가 현재 통합 파일의 실제 국가대표 경기 진행을 검증했다는 뜻은 아닙니다.

## FM26 자체에서 지원하는 기능

FM 공식 안내에 따르면 **26.3.1 업데이트에 국가대표 감독 기능이 추가**됐고, 여자 국가대표팀도 감독할 수 있습니다. Steam에서 최신 FM26 업데이트를 적용하세요.

- [FM26 International Management Update Now Live](https://www.footballmanager.com/news/fm26-international-management-update-now-live): 26.3.1 업데이트와 지원 플랫폼 안내.
- [FM 공식 국가대표 FAQ](https://community.sports-interactive.com/forums/topic/601503-international-management-faq/): SI 직원 Dan Sheppard가 작성한 안내. 10번은 여자 국가대표 감독 가능 여부에 **Yes**라고 답합니다.
- [국가대표 기능 소개](https://www.footballmanager.com/fm26/features/chase-fifa-world-cup-2026tm-glory-international-management-arrives-fm26): 여자 국가대표 감독과 기존 커리어에 기능이 추가되는 방식 안내.

공식 FAQ 7번에 따르면 일반 커리어 시작 방식은 구단과 국가대표 겸임을 지원합니다. **2026 월드컵 전용 빠른 시작은 국가대표만 사용할 수 있는 별도 방식**이므로, 여자 연예인 통합리그와 함께 플레이하려면 일반 고급 설정으로 시작하세요. 이 문서의 여자 국가대표 안내를 남자 2026 월드컵 전용 시작 옵션과 혼동하지 마세요.

## 현재 통합 XML에서 확인한 범위

현재 배포한 `FM26_unified.xml`은 기존 연예인 선수 771명의 주 국적을 대한민국·일본·중국·호주·잉글랜드·프랑스·독일·스페인·네덜란드·스웨덴·노르웨이·덴마크·이탈리아·브라질·캐나다·미국에 48~49명씩 배치합니다. 이는 게임 속 설정이며 실제 인물의 국적을 설명하는 자료가 아닙니다.

선수 주 국적 변경 외에 대표팀 출장 이력, 대표 국가 선언, 복수국적 등 다른 대표 자격 정보까지 모두 정리한 버전은 아닙니다. 기본 데이터에서 물려받은 정보가 있을 수 있어 일부 선수의 대표 자격은 게임에서 확인해야 합니다.

통합 XML에는 스페인 여자 국내 리그 규칙이 있으며, `international_rule_group`은 `null`입니다. **이는 이 XML이 별도의 국제대회 규칙을 제공하지 않는다는 뜻입니다. 이 값만으로 FM 기본 데이터의 국가대표 경기나 월드컵이 모두 꺼졌다고 판단할 수 없습니다.** 이전 문서의 “국적 분산만으로 국가대표 대회가 활성화되지는 않는다”는 표현은 국적 변경만으로 모든 동작을 보장할 수 없다는 의미로 읽어야 합니다. 실제 기본 국제대회의 존재·소집·일정은 새 게임에서 확인해야 합니다.

원 제작자의 별도 연예인 리그 설명에는 자국 선수 영입·출전 제한이 안내돼 있습니다. 그러나 현재 스페인 6단계 통합 XML의 기본·고급 대회 규칙과 구단 변경 기록을 조사한 결과, **명시적인 외국인 영입·등록·출전 제한은 찾지 못했습니다.** 연예인 구단 38곳의 국가 ID가 774라는 사실만으로 제한이 존재한다고 볼 수 없습니다. `Csot`은 외부 인수 방지 속성이며 자국 선수 제한이 아닙니다. 실제 기본 데이터의 특수 정책이나 게임 속 제한 여부는 별도 확인이 필요합니다. 확인하지 못한 제한을 제거했다고 주장하거나 관련 없는 속성을 바꾸지 않았습니다. 자세한 조사 범위와 게임 확인 방법은 [구단 제한 조사 결과](club-restrictions.md)를 참고하세요.

## 새 게임 설정과 확인 순서

1. Steam에서 FM26을 최신 상태로 업데이트합니다. 국가대표 기능은 26.3.1부터 제공됩니다.
2. 에디터에서 사용할 통합 XML 하나를 가져와 전체 6부까지 규칙을 검증하고, `.fmf`로 저장합니다. 다른 원본·수정본을 동시에 선택하지 않습니다.
3. 일반 **고급 설정**으로 새 커리어를 만듭니다. 기존 제작자 안내대로 여자 스페인 리그 6부까지 선택합니다. 다른 여자 리그를 반드시 플레이 가능으로 켜야 국가대표 경기가 진행된다고 단정하지 않습니다.
4. 데이터베이스 크기의 **사용자 지정**에서 대표팀으로 사용할 국가들의 선수들을 충분히 불러오도록 설정합니다. 공식 FAQ 12번은 국가대표팀이 선택 목록에 없을 때, 관련 국가 선수를 추가로 불러오라고 안내합니다. 보편적인 최소 선수 수는 공식 안내에 제시돼 있지 않아 임의 숫자를 기준으로 삼지 않습니다.
5. 시작 후 서로 다른 국가에 배정된 선수 몇 명의 주 국적과 대표팀 참가 자격을 확인합니다. 이어 해당 국가의 **여자** 대표팀 명단·소집·경기 일정을 확인합니다.
6. 여자 월드컵 대회 화면에서 예선·본선 일정과 참가팀이 생성되는지 확인합니다. 국적을 나누었다는 이유만으로 특정 국가의 본선 진출이나 연예인 선수 전원의 소집이 보장되지는 않습니다.
7. 구단에서도 다른 국적 선수의 영입 제안, 등록, 실제 출전이 가능한지 확인합니다. 에디터 규칙 시험 통과만으로 이 동작까지 검증되지는 않습니다.

공식 FAQ 1·13번에 따르면 FM의 국가대표 기능 업데이트는 기존 세이브에도 적용됩니다. **이는 새 XML에 적힌 선수 국적·구단 제한·컵 규칙 변경이 기존 세이브에 소급 적용된다는 뜻은 아닙니다.** 에디터 데이터 변경은 새 커리어에서 적용해야 합니다. 얼굴팩 config 수정은 이와 별개로 기존 커리어에서도 확인할 수 있습니다.

## 국가대표 화면의 선수 사진

공식 FAQ 6번은 2026 월드컵 선수 사진에 관한 질문에 “라이선스 제한으로 국가대표 감독 시 선수 이미지를 사용하지 않는다”고 답합니다. 이 설명만으로 사용자가 설치한 얼굴팩이 모든 여자 국가대표 화면에서 표시되거나 숨겨진다고 단정할 수는 없습니다. **커스텀 얼굴팩의 국가대표 화면 표시 여부는 실제 게임에서 별도로 확인해야 합니다.** 구단 화면에서 이름과 다른 사람의 사진이 뜨는 문제는 별도의 ID 연결 문제로 점검합니다.

이 문서는 2026년 10월 18일 공식 웹 문서와 배포 XML을 확인해 작성했습니다. 이 클라우드에서 FM26 Editor나 실제 게임의 국제대회를 실행한 결과는 아닙니다.
