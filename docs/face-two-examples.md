# 제시카·이현주 얼굴 연결 수정

현재 세이브에서 사용자가 확인한 실제 ID를 사용합니다.

| 선수 | 실제 게임 ID | 올바른 사진 파일 | 기존에 잘못 표시된 사진 |
| --- | --- | --- | --- |
| 제시카 | 2002043293 | 2002043283.png | 림킴 |
| 이현주 | 2002043294 | 2002043284.png | 이경서 |

원본 사진의 하단 이름을 직접 읽어 확인했습니다. 얼굴로 사람을 식별하거나 XML의 후보 번호에 일정 숫자를 더한 결과가 아닙니다. 사진 파일 번호를 바꿀 필요도 없습니다.

## 적용 순서

1. FM26을 종료합니다. 현재 사용하는 연예인 얼굴팩의 `celeb` 폴더를 **게임의 graphics 폴더 밖에** 백업합니다.
2. 다운로드한 `fm26-face-two-player-fix.zip`을 임시 폴더에 압축 해제합니다.
3. 안에 있는 `2부리그/무소속,블리츠웨이,바로엔터,제이와이드/config.xml`을 **현재 얼굴이 표시되고 있는 기존 celeb 폴더 안의 같은 위치**에 복사하고 교체합니다. 팀 로고 폴더에 넣거나 별도 얼굴팩으로 추가하지 마세요.
4. 원래 PNG 사진은 이동하거나 이름을 바꾸지 않습니다. 이전 config를 다른 XML 이름으로 graphics 안에 남기지 않습니다.
5. 게임의 그래픽 캐시를 비우고, 게임을 다시 실행해 제시카와 이현주를 확인합니다. 얼굴 연결만 바꾸므로 기존 세이브에 적용할 수 있습니다.

**제시카와 이현주 두 명만 확인한 수정본입니다. 전체 연예인 얼굴 연결을 고친 파일은 아닙니다.** 다른 세이브에서는 실제 선수 ID가 같은지 먼저 확인해야 합니다. 원본과 다른 버전의 config를 사용하거나 직접 수정한 경우에는 이 파일을 덮어쓰지 말고 [얼굴 연결 복구 도구](face-repair.md)로 현재 파일을 검사하세요.

## 바뀌는 범위

제시카 사진의 연결을 `r-2002043283`에서 `r-2002043293`으로, 이현주 사진의 연결을 `r-2002043284`에서 `r-2002043294`로 바꿉니다. 이미 그 두 대상에 연결돼 있던 림킴·이경서 사진의 잘못된 매핑 2개는 제외해 중복을 없앱니다. 따라서 해당 config의 매핑은 50개에서 48개가 됩니다. 이 두 사진의 올바른 선수 ID는 아직 확인하지 못했습니다. 다른 항목의 잘못된 연결이 남을 수 있습니다.

파일에는 교체용 config와 이 안내 TXT만 있습니다. 사진 원본·CMD·EXE·자동화 실행 프로그램은 포함하지 않습니다. 기존 세이브의 이름·국적·능력치·구단 재정은 바꾸지 않습니다. XML 구문·변경 범위·ZIP CRC를 검사했으며 실제 게임 표시 확인은 필요합니다.
