# 현재 세이브의 연예인 얼굴 연결 복구

컵·국적을 바꾼 FMF는 그래픽의 `config.xml`을 고치지 않습니다. 원본 사진팩에는 플레디스 28장의 이름과 XML 후보 번호가 +7, 자유계약 표본은 +18로 어긋난 증거가 있으며 `SM/1.png` 같은 별도 번호도 있습니다. XML 후보가 현재 세이브 ID와 같다는 보장은 없어 전체를 +7로 바꾸지 않습니다. 받은 여성 메가팩 7,591개와 연예인팩 1,010개 사이에는 같은 대상 경로나 숫자 ID가 없었습니다.

`web/repair.html`을 Edge 또는 Chrome에서 엽니다. 설치·서버·CMD·EXE가 필요 없는 정적 페이지입니다. 파일과 선수 목록을 인터넷으로 보내지 않습니다.

1. 현재 사용하는 **celeb 폴더 전체**를 선택합니다. 각 팀의 원본 `config.xml`과 PNG가 함께 있어야 합니다. 생성기 실행 파일은 읽지 않습니다.
2. **현재 세이브에서 확인한 실제 선수 ID와 이름** 목록을 넣습니다. CSV/TSV의 필수 머리글은 `id,name`이고 `club`은 선택입니다. 한국어 `고유 ID,이름,구단`도 인식합니다. 직접 입력하거나 선수 표가 하나인 HTML 파일을 사용할 수도 있습니다. FM26의 특정 버전에서 목록 출력·ID 열을 제공한다고 가정하지 않습니다. ID 없는 출력물만으로는 복구할 수 없습니다.
   이번에 실제 ID를 확인해 주신 제시카 `2002043293`·이현주 `2002043294`는 **알려주신 두 사례 불러오기** 버튼으로 넣을 수 있습니다. 관련 원본 config와 사진 4장의 SHA-256이 일치할 때만 버튼을 켭니다. 이 두 사례는 사용자가 현재 세이브에서 확인한 ID를 사용하며 XML 후보 번호나 일괄 offset을 사용하지 않습니다. 다른 선수까지 복구했다는 뜻은 아닙니다.
3. 현재 여자 연예인 선수 명단인지 확인하고 **이름·사진·충돌 대조하기**를 누릅니다. 사진, 실제 ID와 충돌 영향을 확인합니다.
4. 원본 config를 **graphics 밖에 백업**한 뒤 교체 ZIP을 받습니다. ZIP을 임시 폴더에 풀고, `SM/config.xml` 같은 구조를 그대로 현재 `celeb` 폴더 안에 복사해 **기존 config를 교체**합니다. 원래 PNG는 유지합니다. ZIP에는 사진이 없습니다. 이전 config를 다른 XML 이름으로 graphics 아래에 남기면 중복 로딩이 생길 수 있습니다.
5. FM26을 완전히 종료하고 다시 실행해 기존 세이브를 불러옵니다. 제공되는 캐시 초기화·그래픽 새로고침 기능도 사용할 수 있습니다. 실제 표시를 확인합니다. 되돌릴 때는 백업한 원래 config를 복원합니다.

얼굴 연결 교체에는 새 게임이 필요하지 않습니다. 국적·구단 규칙을 바꾼 FMF의 적용 조건과는 별개입니다.

## 자동 복구 범위와 충돌

페이지에 표시되는 **현재 검수 사진 목록의 수량**을 기준으로 대조합니다. 별도 `repair-catalog.js`가 있으면 그 전수 캡션 목록을 사용하고, 없는 이전 묶음에서는 기존 목록과 이현주 검수 사진으로 제한됩니다. 여러 사진이나 여러 실제 선수에게 같은 이름이 있으면 제외합니다. 이름이 정확히 같거나 목록에 명시된 검수 별칭인 경우만 연결하며, 비슷한 이름·사진 번호·공통 번호 차이를 추정해 연결하지 않습니다. 사진의 원본 SHA-256이 다르거나 경로·ID·XML에 문제가 있으면 출력을 중단합니다.

**사진의 이름 캡션을 전부 읽었더라도 현재 세이브의 모든 실제 ID가 확인됐다는 뜻은 아닙니다.** 이름 목록 검수, 실제 선수 명단과의 대조, FM26에서의 얼굴 표시 확인은 각각 필요한 단계입니다. 이 페이지의 수량과 출력 결과는 현재 입력한 실제 명단에만 해당합니다.

기존 config의 `r-` 유무와 사진의 `from` 경로를 유지합니다. 확인된 사진의 `to` 값만 실제 ID로 바꾸고, 그 실제 ID에 겹치는 **다른 사진 매핑은 선택한 폴더의 모든 config에서 찾아 제외**합니다. 서로 이동하는 수정 대상 사진은 새 연결로 유지합니다. XML 전체를 재생성하지 않고 원래 문자열의 해당 속성·확정 충돌 record 구간만 바꾸므로 다른 설정·주석·알 수 없는 매핑은 유지합니다.

충돌을 제외하면 아직 실제 이름·ID가 확인되지 않은 다른 사진이 연결을 잃을 수 있습니다. 미리보기와 `UNMAPPED_PHOTOS.csv`에 그 목록을 표시합니다. 그 사진까지 올바르게 고쳤다는 뜻은 아닙니다. 출력한 `VERIFIED_CONNECTIONS.csv`는 연결 근거이며 `REMOVED_CONFLICTS.csv`는 제외한 매핑 목록입니다. 선택한 celeb 폴더 밖의 팩은 검사하지 않습니다. 동일 ID를 가진 다른 설치본·도우미 폴더가 있으면 별도 확인이 필요합니다.

이 도구는 선수 이름·국적·나이·능력치·게임 메모리·세이브 파일을 수정하지 않습니다. 실제 FM26의 그래픽 표시 결과는 사용자 게임에서 확인해야 합니다.
