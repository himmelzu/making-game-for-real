# FM26 후속 수정판 — 먼저 읽기

**새 게임 데이터는 `1_게임데이터`, 기존 세이브의 얼굴 연결은 `2_기존얼굴_수정`입니다. 서로 다른 곳에 적용합니다.** 이 묶음에는 에디터 XML 하나, 사진 없는 얼굴 연결 config, 설치 없이 여는 얼굴 도구와 설명서가 있습니다. 사진 원본은 포함하지 않습니다.

## 처음 사용하는 순서: 세 단계

1. **새 게임을 만들려면:** `1_게임데이터/FM26_unified_funded.xml`을 FM26 Pre-Game Editor에서 가져옵니다. 전체 6부까지 규칙을 검증하고 새 이름의 FMF로 저장합니다. 그 FMF 하나를 선택해 **새 게임**을 시작합니다. 원본과 수정본을 함께 선택하지 마세요. XML 확장자를 FMF로 바꾸면 안 됩니다. 이미 진행 중인 세이브의 국적·나이·재정은 이 XML로 바뀌지 않습니다.
2. **기존 세이브 얼굴을 고치려면:** 현재 `celeb` 폴더를 먼저 graphics 밖에 백업합니다. `2_기존얼굴_수정` 안의 리그·소속사 폴더 구조를 기존 `celeb` 안에 복사해 해당 `config.xml`만 교체합니다. 원래 PNG는 그대로 둡니다. 이 config를 `editor data`에 넣지 마세요. FM26을 완전히 종료한 뒤 다시 실행해 얼굴을 확인합니다. 얼굴 연결 교체에는 **새 게임이 필요하지 않습니다.** 백업한 config를 graphics 아래 다른 XML 이름으로 남기지 마세요.
3. **유소년이나 다른 세이브 얼굴을 만들려면:** `3_얼굴_도구/face.html`을 Edge 또는 Chrome으로 엽니다. 현재 세이브에서 확인한 실제 ID를 넣고, 현재 사용하는 사진의 하위 폴더를 선택해 내보냅니다. 폴더 선택과 모든 작업은 브라우저 안에서 처리합니다. 새 출력은 `config.xml`과 고유한 이름의 PNG를 같은 폴더에 둡니다. 생성 선수는 보통 `r-ID`, 기본 DB 선수는 숫자 ID를 선택합니다. 내보낸 파일을 graphics에 설치하고 다시 실행해 확인합니다. 사진만 바뀌며 선수 이름은 직접 바꿔야 합니다.

`3_얼굴_도구/index.html`은 시즌별 유소년 얼굴 배정·기록 도구입니다. `repair.html`은 사진 폴더와 **실제 세이브 ID·이름 명단**을 대조하는 얼굴 복구 도구입니다. 다른 세이브에는 실제 ID가 달라질 수 있으므로 명단으로 다시 대조하세요. 새 도구 출력은 예전 `faces/face_0001.png` 하위 경로 대신, config 옆의 `fm26_celeb_실제ID.png`처럼 고유한 파일명을 사용합니다. FM26의 경로·파일명 호환성 보고를 반영한 변경이며 실제 게임 표시 확인은 필요합니다.

## 게임 데이터에서 바뀌는 내용

기존 통합본의 리그·컵 구성과 검수된 연예인 771명의 나이·16개국 국적 분산을 이어받습니다. 같은 선수의 과거 UID에 남아 있던 국적 723개·생년월일 51개 변경 기록을 해당 선수의 통제된 최종 값과 맞췄습니다. 선수 UID를 바꾸거나 모든 국적을 한국으로 덮어쓰지 않습니다. 16개국에 48~49명씩 배치되며, 나이는 2025-07-01 기준 18~22세 설정입니다. XML의 처리 순서와 실제 반영 결과는 에디터·게임에서 확인해야 합니다.

1~6부 **500팀 모두**에 매 시즌 8월 11일 각 팀 `100,000,000`의 기본 참가 지원금을 설정했습니다. 부모 리그에 한 경로씩 두어 하위 그룹과의 중복 지급을 피했습니다. 원본에서 기존 재정 기록을 직접 확인한 **39구단만** 시작 잔액 `100,000,000`, 이적 예산 `50,000,000`, 남은 선수 급료 예산 `1,000,000`으로 바꿨습니다. **500팀의 시작 재정을 전부 같게 맞춘 것은 아닙니다.** 다른 수입·부채·명성·이사회 결정도 달라집니다.

이 숫자는 에디터 XML의 원시 금액입니다. 표시 통화 환산과 급료의 주기(주급 등)는 독립적으로 확인하지 못했습니다. 첫 시즌 지급 시점과 다음 시즌 반복 지급도 실제 게임에서 확인해야 합니다. 국적 분산만으로 다른 국가대표팀과 국제대회가 활성화되거나, 구단의 자국 선수 영입 제한이 해제되지는 않습니다. 상세 범위는 함께 들어 있는 예산·국제대회·구단 제한 설명서를 참고하세요.

## 얼굴 연결의 확인 범위

사용자가 현재 세이브에서 확인한 실제 ID는 카리나 `2002042553`, 배성연 `2002042923`, 제시카 `2002043293`, 이현주 `2002043294`입니다. 이 네 사례는 원본 XML에서 **각 선수의 최신 변경 기록 UID 하위 32비트에 +3**을 적용한 값과 일치합니다. 최초 생성 ADDR이나 명단의 통제 UID에 +3을 더하는 방식이 아닙니다. 전체 얼굴 연결팩을 사용하는 경우 이 세이브 기준으로 보정한 것입니다. **다른 선수의 모든 ID를 게임에서 직접 확인한 것은 아니며, 다른 세이브에도 +3이 적용된다고 보장하지 않습니다.**

이번 전체 보정본은 사진 963장을 검사해 **959개 대상 ID**에 연결합니다. SM의 추가 사진 네 장은 정규 숫자 사진과 같은 대상이어서 중복 매핑만 제외했습니다. 원본 PNG는 삭제하지 않습니다. 기존 스태프 연결 중 수정 대상과 겹치는 여섯 개를 제외하고 나머지 41개는 유지합니다.

사진 자막이 약칭·예전 이름이거나 소스 명단과 다른 46건은 보고서에 표시했습니다. 이 항목까지 실제 사람의 동일성을 얼굴로 판별한 것은 아닙니다. `4_검사결과/얼굴팩`의 보고서에서 선택 근거와 차이를 확인할 수 있습니다. 사진 캡션 검수와 실제 게임 ID 확인은 서로 다른 작업입니다. 교체 config는 33개이며 사진은 포함하지 않습니다.

얼굴 복구 도구의 검수 목록은 963장이고, 중복 대체 사진 네 장을 뺀 959장을 자동 대조합니다. 동명이인은 임의로 선택하지 않습니다. 시즌별 유소년 도구는 963장의 원본 자막 이름·사진 목록을 사용하며, 같은 인물의 다른 사진이 있을 수 있습니다.

## 검증과 보안

원본 통합 XML SHA-256은 `247c644252d2e1312c579bd6633a26788163e5d027d888f193931621d762963b`입니다. 빌더는 이 원본을 확인한 뒤 패치하며, ZIP CRC·파일 목록·각 파일 SHA-256·XML 구조를 검사합니다. `4_검사결과/manifest.json`에 포함 파일의 해시가 있습니다.

**이 환경에는 실제 FM26과 FM26 Editor가 없습니다.** 정적 데이터 검사와 브라우저 검사는 FMF 컴파일, 규칙 검증, 실제 경기·재정·국적·얼굴 표시를 증명하지 않습니다. 새 XML은 아직 게임에서 검증한 FMF가 아닙니다. 새 게임 전에 에디터에서 검사하고 별도 시험 세이브로 확인하세요. 기존 원본과 세이브 백업을 보관하세요.

Defender에서 Trojan으로 탐지됐다고 보고된 **Windows 자동화 v3는 배포 중단 상태**입니다. 이 묶음에는 자동화 폴더·런타임·런처·Python·CMD·EXE·DLL을 넣지 않았습니다. 백신 해제나 예외 등록은 필요하지 않습니다. 설치 없이 여는 정적 얼굴 도구만 포함합니다.
