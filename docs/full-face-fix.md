# 현재 세이브용 전체 연예인 얼굴 연결

`fm26-face-current-save.zip`은 기존 연예인 얼굴팩의 **33개 config.xml**을 교체하는 파일입니다. 이름을 검토한 사진 963장을 검사해 중복 대상을 정리하고 **959개 인물 ID**에 사진을 연결합니다. 원본 PNG는 그대로 사용합니다.

## 확인된 범위

현재 세이브에서 사용자가 확인한 실제 ID 네 개가 기준입니다.

| 이름 | 사용자가 확인한 실제 ID |
| --- | ---: |
| 카리나 | 2002042553 |
| 배성연 | 2002042923 |
| 제시카 | 2002043293 |
| 이현주 | 2002043294 |

네 기준점에서는 소스 XML의 같은 인물에 속한 **마지막 변경 기록 UID의 하위 32비트 + 3**이 실제 ID와 일치합니다. 이 규칙과 사진 하단에 인쇄된 이름을 이용해 나머지 연결을 계산했습니다. 기존 사진 파일 번호에 일괄적으로 3이나 10을 더한 결과가 아닙니다.

나머지 **955개 인물**의 실제 ID와 얼굴 표시는 게임에서 개별 확인하지 않았습니다. 보고서의 `current_save_calibrated_model`은 네 기준점으로 보정한 **현재 세이브용 추정 모델**이라는 뜻입니다. 다른 세이브나 다른 버전의 데이터에서도 같은 ID가 된다는 보장은 없습니다. 사진의 얼굴 모양으로 사람을 판별하지 않고, 인쇄된 이름·폴더 위치·소스 인물 기록을 사용했습니다.

같은 이름도 폴더와 기록을 함께 확인합니다. 예를 들어 `MLD 드림티/2002042952.png`에 인쇄된 `이혜인`은 해당 폴더의 번호 순서 모델에 따라 소스 인물 `이혜빈`과 연결합니다. 하이브의 `이혜인`과는 다른 인물로 취급하며, 이름 차이는 보고서에 검토 경고로 남깁니다. `윤아`는 소스 이름 `임윤아`에 대응하는 명시적 별칭을 사용합니다. 같은 인물에게 연결되는 SM 폴더의 추가 사진 `1.png`~`4.png`는 연결에서 제외하고 정규 숫자 파일명의 사진을 사용합니다. 제외한 사진 원본은 삭제하지 않습니다.

이름 검토 대상 밖의 기존 스태프 등 47개 연결 중 수정 대상 ID와 충돌하는 6개는 제외하고 41개는 유지합니다. 이 41개의 인물과 사진은 이번 모델로 검증하지 않았습니다. 따라서 전체 config에는 수정한 959개와 유지한 41개를 합쳐 1,000개 연결이 있습니다.

## 적용 순서

1. FM26을 완전히 종료합니다.
2. 현재 사용하는 연예인 얼굴팩의 `celeb` 폴더를 **게임의 graphics 폴더 밖에** 복사해 백업합니다.
3. ZIP을 임시 폴더에 압축 해제합니다. 교체용 config를 **현재 얼굴이 표시되고 있는 기존 celeb 폴더의 같은 상대 경로**에 복사하고 덮어씁니다. 예를 들어 `SM/config.xml`은 기존 `celeb/SM/config.xml`을 교체합니다.
4. 원래 PNG 사진은 이동하거나 이름을 바꾸지 않습니다. 이전 config를 다른 XML 이름으로 graphics 안에 보관하지 않습니다. 앞서 적용한 두 명 수정본이나 같은 ID를 연결하는 별도 config가 있다면 graphics 밖으로 옮깁니다.
5. 게임의 그래픽 캐시를 비우고 게임을 다시 실행합니다. 네 기준 인물과 각 폴더의 여러 선수를 확인합니다. 잘못 표시되면 종료한 뒤 백업 config를 복원합니다.

원본과 다른 얼굴팩을 쓰거나 config를 직접 편집한 경우에는 덮어쓰기 전에 [얼굴 연결 복구 도구](face-repair.md)로 현재 파일을 확인하세요. 압축 안의 보고서에는 적용 범위, 각 사진의 원래 연결과 계산한 ID, 선택·제외 이유가 기록됩니다.

## 바뀌는 범위

이 파일은 사진 연결 config와 안내·검사 보고서만 포함합니다. 세이브 파일이나 에디터 데이터 XML을 바꾸지 않으므로 기존 세이브에 적용할 수 있습니다. 선수 이름·국적·나이·능력치·구단 재정에는 영향을 주지 않습니다. 사진이나 실행 프로그램도 포함하지 않습니다.

XML 구문, 참조하는 사진 파일, 대상 ID 중복과 ZIP CRC를 검사합니다. 이 검사는 파일 구성을 확인하며, 나머지 선수의 실제 게임 표시 확인은 필요합니다.
