# FM26 여자슈퍼연예인리그 편집 자료

Windows Steam FM26 Editor에서 확인할 **XML 초안**과 기존 사진을 유소년 ID에 연결하는 오프라인 도구입니다. 완성된 FMF가 아니며 게임/에디터 실행 검증은 아직 수행하지 못했습니다.

[검증용 자료 ZIP](downloads/fm26-review.zip)을 연 뒤 GitHub의 파일 다운로드 버튼으로 받습니다. ZIP의 `start_here.txt`부터 읽으세요.

- `cups_test.xml`: 내셔널리그컵 4~6부 확대와 새 컵 3개가 포함된 실험용 초안.
- `cup_expansion_only.xml`: 새 대회 없이 내셔널리그컵만 확대한 별도 선택지.
- `index.html`, `core.js`, `app.js`: 이미 생성된 유소년의 실제 ID에 사진을 연결하는 로컬 도구.
- `pledis_config_candidate.xml`: 플레디스 28장의 +7 번호 보정 후보. 실제 게임 ID 확인 후 사용.
- `photo_report.txt`, `megapack_report.txt`: 이름/ID 대조 및 여성 메가팩 설정 비교 결과.

여성 메가팩 7,591개 매핑과 기존 연예인팩 1,010개는 대상이 겹치지 않았습니다. 실제 여성 메가팩 이미지 파일은 받지 않아 이미지 존재 여부는 미확인입니다. [상세 설정 비교](docs/megapack-audit.md)

원본 선수 변경 기록은 보존했습니다. 두 XML이나 원본과 수정본을 동시에 적용하지 않습니다. FM26 Editor에서 전체 6부까지 규칙 검증을 마친 뒤 별도 이름의 FMF로 저장해야 합니다. 새 컵 등록의 ADDR/COPY 처리, 전체 기본 DB의 ID 충돌, 향후 시즌 일정과 반복 개최는 게임 에디터에서 확인해야 합니다.

국적 분산 실제 적용·국가대표 대회 활성화·매년 연예인 유소년 자동 생성·노화와 은퇴 자동 방지는 아직 포함하지 않았습니다. 얼굴 연결 도구가 새 선수를 생성하거나 이름을 바꾸지는 않습니다.

원자료: 사용자가 제공한 Yontarak 연예인 로스터와 여자 슈퍼리그 통합 Ver3 자료를 바탕으로 한 편집 초안입니다. 그래픽 원본이나 얼굴 사진은 이 저장소에 포함하지 않습니다.
