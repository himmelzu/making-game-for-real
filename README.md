# FM26 여자슈퍼연예인리그 · 장기 커리어 도우미

[Windows 자동화 실험판 v3 다운로드](https://github.com/himmelzu/making-game-for-real/raw/refs/heads/main/downloads/fm26-auto-beta-v3.zip)

v3에는 실행 중인 FM26을 읽어 CSV 없이 선수 후보를 찾고, 기존 DB의 연예인 이름 4항목과 얼굴팩을 일괄 적용하는 코드가 들어 있습니다. 기존 보호 선수의 능력치 고정·28세 이상→22세 조정도 포함합니다. ZIP을 모두 풀고 `Start.cmd`로 실행합니다. Python은 동봉합니다.

**실제 FM26에서 이름 변경 후 저장·재로드를 검증하지 못한 실험판입니다.** 이름 참조의 수명·저장 영속화는 미검증이며 완전 무인 실행·전체 은퇴 방지는 제공하지 않습니다. 알려진 버전과 구조를 확인하지 못하면 쓰기를 막습니다. 별도 세이브에서 먼저 확인해야 합니다. [v3 사용법과 한계](docs/automation.md) · [구조 출처](docs/automation-research.md)

유소년 입단 때 **스캔 → 후보 확인 → 일괄 적용**하는 방식입니다. 진행 중인 세이브의 기존 14~18세 여성 선수도 선택적으로 후보에 넣을 수 있습니다. 뒤늦게 로드된 실존 선수도 후보가 될 수 있어 대상 확인은 필요합니다. 새 세이브·과거 세이브 분기는 새 커리어 이름으로 등록합니다.

아래는 기존 v2 자료에 대한 설명입니다. v2의 FMF·XML은 자동화 앱과 별도로 보존했습니다.

[새 통합판 ZIP 다운로드](https://github.com/himmelzu/making-game-for-real/raw/refs/heads/main/downloads/fm26-longplay-v2.zip) · [처음 검증한 자료](downloads/fm26-review.zip)

ZIP을 모두 풀고 `START_HERE.txt`를 읽은 뒤 `web/index.html`을 Edge 또는 Chrome으로 여세요. 사진은 기존 `celeb` 폴더를 선택하면 됩니다. 추가 사진은 필수가 아닙니다.

**기존 v2에는 게임의 자동 연예인 유소년 생성, 자동 이름 변경, 노화·은퇴 중지가 없습니다.** v2의 이름과 생년월일 변경은 인게임 에디터 수동 작업입니다. 새 v3는 별도 프로그램에서 실험적으로 일괄 이름·나이 적용을 시도하는 버전이며, 시작 나이 XML 자체가 노화를 멈추는 것은 아닙니다. [v2 적용 순서와 한계](docs/start-here.md)

기본 이름 목록은 기존 사진 자막을 읽어 확인한 118장입니다. 사진을 재사용할 수 있고, 직접 구한 사진과 이름도 CSV로 추가할 수 있습니다. 검수 전 사진 845장의 번호를 추정해 이름에 연결하지 않습니다. 최신 연예인 명단을 새로 조사해 추가한 버전은 아닙니다. [사진 점검](docs/photos.md)

도구의 30회 시즌 기록 반복, 구단 이동, 중복 입력, ZIP CRC·원본 사진 해시를 검사했습니다. Chromium에서도 실제 사진을 사용해 ZIP 출력·기록 복원·다음 시즌 배정·HTML 표 입력을 확인했습니다. **FM26 게임에서 30시즌을 진행한 시험은 수행하지 못했습니다.**

개발 확인: Python 3.10 이상, Node 18 이상에서 `bash .codex/setup.sh`. 외부 패키지·비밀키·상시 서버가 필요 없습니다. [개발과 재생성](docs/development.md)

원자료는 사용자가 제공한 Yontarak 연예인 로스터와 여자 슈퍼리그 통합 Ver3입니다. 원 제작자의 자유로운 수정·재배포 안내를 바탕으로 편집했습니다. 원본 얼굴 사진·생성기 EXE·여성 메가팩 이미지는 배포에 포함하지 않습니다. [여성 메가팩 비교](docs/megapack-audit.md)
