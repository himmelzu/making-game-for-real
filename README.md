# FM26 여자슈퍼연예인리그 · 장기 커리어 도우미

[이번 후속 통합 수정판 다운로드](https://github.com/himmelzu/making-game-for-real/raw/refs/heads/main/downloads/fm26-followup.zip) · [처음 적용하는 순서](docs/followup.md)

- **새 게임 데이터:** 컵·시작 나이·국적 분산을 포함한 에디터 XML 하나에 재정 지원을 더했습니다. 500팀에 매년 같은 기본 지원금을 설정하고, 재정 기록이 확인된 연예인 39구단의 시작 예산을 증액합니다. 500팀의 시작 예산을 모두 같게 만든 것은 아닙니다.
- **현재 세이브 얼굴:** 사진 963장을 대조한 33개 config로 959개 대상 ID를 보정합니다. 현재 세이브에서 확인한 카리나·배성연·제시카·이현주 네 ID를 기준으로 보정한 모델이며, 나머지 955개 ID를 게임에서 직접 확인한 것은 아닙니다. [전체 얼굴 보정 범위](docs/full-face-fix.md)
- **유소년 사진 도구:** 사진과 config를 같은 폴더에 두고, 실제 ID가 들어간 고유 파일명을 사용하도록 고쳤습니다. 생성 선수와 기본 DB 선수를 구분할 수 있고 파일 배치 검사도 추가했습니다. 시즌별 이름·사진 배정 목록도 118장에서 963장으로 확대했습니다. [사진 표시 문제와 검사법](docs/youth-face-compatibility.md)

에디터에는 `1_게임데이터` 안의 XML **하나만** 가져와 6부까지 규칙을 검증한 뒤 FMF로 저장합니다. `2_기존얼굴_수정`은 기존 `celeb`의 config 교체용이고, 얼굴 수정에는 새 게임이 필요하지 않습니다. 새 게임의 나이·국적·재정 변경은 기존 세이브에 소급 적용되지 않습니다. 이 환경에서는 실제 FM26이나 Editor를 실행하지 못했습니다.

여자 국가대표 기능은 FM26 공식 업데이트에서 지원합니다. 현재 통합 XML에서 명시적인 자국 선수 전용·외국인 한도는 찾지 못했으며, 원본 단독 리그의 제한 설명만으로 현재 통합본의 충돌을 단정하지 않습니다. [국가대표 설정](docs/internationals.md) · [구단 제한 조사](docs/club-restrictions.md) · [예산 범위](docs/budgets.md)

아래는 이전 자료입니다. 현재 수정은 위 후속 통합판을 사용하세요.

[에디터용 단일 XML 통합 자료 다운로드](https://github.com/himmelzu/making-game-for-real/raw/refs/heads/main/downloads/fm26-unified-data.zip) · [적용 순서](docs/unified-editor.md)

이번 자료에는 `FM26_unified.xml` 하나와 적용 안내 TXT만 있습니다. 기존 v2의 가장 많은 기능이 들어간 XML을 이름만 정리한 사본으로, 컵 수정·시작 나이 조정·16개국 국적 분산이 함께 들어 있습니다. CMD·EXE·Python은 포함하지 않습니다. 국적 분산은 실험 설정이며 국제대회 활성화나 기존 구단의 자국 선수 제한 해결을 보장하지 않습니다. FM26 Editor에서 새로 규칙 검증 후 FMF로 저장하고, 새 게임에 그 FMF 하나만 선택합니다.

**2026-10-18: Windows 보안이 자동화 v3 ZIP을 `Trojan:Script/Sabsik.Fl.A!ml`로 탐지했다는 보고를 받아 배포를 중단했습니다.** 현재 브랜치의 ZIP 다운로드를 회수했으며, 악성 여부나 오탐 여부를 확정하지 못했습니다. 파일을 실행하거나 격리에서 복원하지 마세요. [탐지 사실과 확인 범위](docs/security-review.md)

v3 소스는 원인 조사를 위해 보존합니다. 아래 v2는 FM26 Editor용 데이터와 브라우저 도우미이며, 회수한 Windows 실행 패키지와 별개입니다. 소스·공식 Python과 배포물의 해시가 일치한다는 검사만으로 백신 경고를 무시할 수는 없습니다.

**기존 v2에는 게임의 자동 연예인 유소년 생성, 자동 이름 변경, 노화·은퇴 중지가 없습니다.** v2의 이름과 생년월일 변경은 인게임 에디터 수동 작업입니다. 자동화 v3는 보안 탐지 보고로 배포를 중단했습니다. 시작 나이 XML 자체가 노화를 멈추는 것은 아닙니다. [v2 적용 순서와 한계](docs/start-here.md)

기본 이름 목록은 기존 사진 자막을 읽어 확인한 118장입니다. 사진을 재사용할 수 있고, 직접 구한 사진과 이름도 CSV로 추가할 수 있습니다. 검수 전 사진 845장의 번호를 추정해 이름에 연결하지 않습니다. 최신 연예인 명단을 새로 조사해 추가한 버전은 아닙니다. [사진 점검](docs/photos.md)

도구의 30회 시즌 기록 반복, 구단 이동, 중복 입력, ZIP CRC·원본 사진 해시를 검사했습니다. Chromium에서도 실제 사진을 사용해 ZIP 출력·기록 복원·다음 시즌 배정·HTML 표 입력을 확인했습니다. **FM26 게임에서 30시즌을 진행한 시험은 수행하지 못했습니다.**

개발 확인: Python 3.10 이상, Node 18 이상에서 `bash .codex/setup.sh`. 외부 패키지·비밀키·상시 서버가 필요 없습니다. [개발과 재생성](docs/development.md)
